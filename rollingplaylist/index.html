Rolling Playlist

A small personal utility for keeping one YouTube playlist current.

Rolling Playlist is a private, single-user script. It keeps one YouTube playlist stocked with recent uploads from a short, hand-picked list of channels, so those videos can be browsed as a single ordered list on a television instead of navigating a large subscription grid.

What it does

  • Reads the recent uploads of a set of YouTube channels chosen by the owner.
  • Adds new videos from those channels to one playlist the owner designates.
  • Optionally removes videos from that playlist once they pass a chosen age.

What it is not

  • Not a hosted service. It runs on the owner's own computer.
  • Not multi-user. There are no accounts, no sign-up, and no other users.
  • Not commercial. Nothing is sold, and no advertising is served.

How it runs

It is a small Node.js script run on a schedule on a personal machine. It talks only to Google's YouTube Data API, using credentials belonging to the account owner. No other network services are involved.

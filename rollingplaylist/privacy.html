Privacy Policy

Rolling Playlist · effective 26 August 2026

Rolling Playlist is a private, single-user utility operated by its owner on the owner's own computer. It has no other users, collects nothing from visitors to this page, and transmits no data to anyone.

Google user data accessed

With the owner's explicit authorization, and using only the https://www.googleapis.com/auth/youtube scope, the application accesses the following from the owner's own YouTube account:

  • Subscription list — read once, to help the owner assemble a list of channels to follow.
  • Public upload listings of the channels on that list — video titles, publication dates, durations, and video identifiers.
  • Playlists — read, to see what a designated playlist already contains; and write, to add or remove videos in that one playlist.

The application does not access watch history, private videos, comments, messages, contacts, payment information, or any Google service other than YouTube.

How the data is used

Solely to add recent videos from the owner's chosen channels to one playlist the owner designates, and — where the owner enables it — to remove videos from that playlist once they exceed a chosen age. There is no other purpose.

Sharing and disclosure

None. Data is not sold, rented, shared, transferred, or disclosed to any third party. There are no advertisers, no analytics providers, no trackers, and no third-party processors. Data is not used to train any machine-learning or AI model. The only network destination the application contacts is Google's own API endpoints.

Storage and protection

Two things are stored, both on the owner's own computer and nowhere else:

  • An OAuth refresh token, held in a local configuration file that is excluded from version control.
  • A list of video identifiers already added to the playlist, so that a video removed by hand is not added again.

No database, server, or cloud storage is used. Nothing is transmitted off the owner's machine except the API requests to Google described above, which are sent over HTTPS.

Retention and deletion

The stored video-identifier list is pruned automatically after 180 days. All stored data can be destroyed at any time by deleting the application's local configuration and state files. Access can be revoked independently and immediately at myaccount.google.com/permissions, which invalidates the refresh token and ends the application's access to the account.

Changes to this policy

If the application's data handling changes, this page will be updated and the effective date above revised.
